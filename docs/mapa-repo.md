Lido sob demanda (#753): o `AGENTS.md` traz só as regras e aponta para cá. Aqui fica onde cada coisa mora e qual teste a cobre. PR que cria comando, pasta ou teste novo atualiza este arquivo, não o `AGENTS.md`. Este arquivo não é prompt fixo de sessão, então não tem teto de tamanho (`docs/prompts-teto.md`).
