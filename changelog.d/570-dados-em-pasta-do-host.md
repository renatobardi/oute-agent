### Added
- **Dados do agent-studio e do SurrealDB numa pasta do host** (#570). `OUTE_AGENT_STUDIO_DIR` (DuckDB) e `OUTE_SURREALDB_DIR`, no `.env` ou no ambiente, montam uma pasta do host no lugar do volume docker. No oute-server elas apontam para o disco de dados: o DuckDB guarda tudo, sem retenção, e cresce ~290 MB por dia, o que encheria o disco do sistema. O `oute up` para antes de subir se o caminho é relativo, se a pasta não existe ou se o dono não é o usuário do container (10001): o Docker criaria uma pasta vazia e o agent-studio subiria com um banco novo, como se o histórico tivesse sumido. Sem as variáveis, nada muda (volume docker). **Não precisa de release** (`compose.yaml` e `scripts/oute` entram com `git pull`); a mudança dos dados é um passo manual no host.
