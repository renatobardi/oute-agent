### Added
- **Sessão interativa de worktree sob `ai-memory run`, opt-in** (#367). Com `OUTE_MEMORY_RUN=1`, o shim de `claude`/`codex` abre a sessão com terminal, dentro de uma worktree e sem headless/subcomando/resume como `ai-memory run <agente> --no-autowire --executable <binário real> -- <args>` (sem `--yolo`), para o Codex continuar a tarefa na mesma worktree quando a cota do Claude estoura (`ai-memory run codex`). Desligado por padrão (vazio ou `0`: comportamento de antes); `AI_MEMORY_RUN_ID` já definido passa direto, `ai-memory` ausente passa direto com aviso. `docker/comandos.md` e `docker/agent-notes.md` ganham a nota. **Precisa de release** (o shim e `docker/agent-notes.md` vão na imagem).
