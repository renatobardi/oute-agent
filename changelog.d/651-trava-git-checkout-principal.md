### Added
- **Trava do `git` no checkout principal** (#651). No checkout principal de um repo de `/workspace` (`/workspace/<repo>`, com `git rev-parse --git-dir` igual a `--git-common-dir`), `git checkout`, `git switch`, `git commit`, `git merge` e `git rebase` são recusados com o código 77 e a mensagem "abra uma worktree: oute-task <slug>". Continuam passando: todo comando de leitura, `git fetch`, `git pull --ff-only`, `git worktree add` e `git merge --ff-only` na branch padrão sem mudança local (o que o `oute-task clean --yes` usa). Dentro de uma worktree e em repo de outra pasta (`/tmp`, repo temporário de teste) nada muda. A trava protege contra engano, não contra contorno (`/usr/bin/git`, `bash -c` com outro PATH, alias do git). **Precisa de release** (o `docker/shims/git` vai na imagem).
