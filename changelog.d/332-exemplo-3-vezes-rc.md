### Fixed
- **Worker do swarm: o exemplo das 3 execuções devolve código de erro quando o teste falha** (#332). No `docker/swarm-worker.md`, na linha dos dois ambientes, o exemplo `for i in 1 2 3; do bash tests/<x>.test.sh || break; done` saía com código 0 mesmo com uma execução falha (o `break` zera o código do laço), e quem conferia pelo código de saída via verde. O exemplo novo, `(for i in 1 2 3; do bash tests/<x>.test.sh || { echo "falhou na execução $i" >&2; exit 1; }; done)`, sai com código diferente de 0 na primeira execução que falha e diz qual foi. Lição da rodada `swarm-1003-0457` (achado da auditoria do #323). **Precisa de release** (`docker/swarm-worker.md` vai na imagem).
