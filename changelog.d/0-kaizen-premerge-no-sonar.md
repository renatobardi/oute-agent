### Changed
- **`oute-swarm premerge` dispensa o check `SonarCloud Code Analysis` ausente só em repo sem projeto no SonarCloud (#869).** Antes, um repo sem projeto (ex.: `renatobardi/oute-catalog`) era recusado com saída 4 mesmo com os outros checks verdes. Agora o check só é dispensado quando o novo modo `oute-sonar project` responde que o projeto não existe (404); com o check presente, ele segue obrigatório, e qualquer outra resposta do `oute-sonar` mantém a recusa. Novo modo `oute-sonar project` (leitura, só GET). **Precisa de release** (o `docker/oute-sonar` e o `docker/oute-swarm` vão na imagem).
