### Changed
- **`oute-swarm premerge` waives a missing `SonarCloud Code Analysis` check only for a repo with no SonarCloud project (#869).** Before, a repo with no project (e.g. `renatobardi/oute-catalog`) was refused with exit 4 even when every other check was green. Now the check is waived only when the new `oute-sonar project` mode reports that the project does not exist (404). With the check present, it stays required, and any other answer from `oute-sonar` keeps the refusal. New `oute-sonar project` mode (read-only, GET only). **Needs release** (`docker/oute-sonar` and `docker/oute-swarm` ship in the image).
